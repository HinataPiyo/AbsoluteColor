# AbsoluteColor — ゲーム概要

## ゲーム概要

AbsoluteColorは、ランダムに提示される見本色にRGBスライダーで近づけるカラーマッチングゲームです。5ラウンド制で、各ラウンドの色差に応じた採点を行い、全ラウンド終了後に合計スコアとランクを表示します。

## 基本情報

| 項目 | 内容 |
|---|---|
| タイトル | AbsoluteColor |
| ゲームジャンル | ラウンド制カラーマッチングゲーム |
| 総ラウンド数 | 5ラウンド |
| 操作 | R/G/Bスライダー、決定ボタン |
| シーン構成 | ホーム画面、ゲームプレイ画面 |
| 開発環境 | Unity 6000.3.13f1、C#、Universal Render Pipeline 17.3.0 |

## ゲーム進行

1. ホーム画面で色チャンネルデータを選択し、ゲーム開始
2. 各ラウンドでランダムな見本色を表示
3. RGBスライダーで色を調整し、プレビュー画面で確認
4. 決定ボタンまたは時間切れで回答確定
5. 色差に基づいて判定、スコア、割合を表示
6. 5ラウンド終了後に合計スコア、ランク、各ラウンド結果を表示

## 主要システム

### 制限時間

初回ラウンドは15秒。以降のラウンドは前ラウンドの0.9倍（10%短縮）。

### 採点

回答色と見本色のRGB各成分の絶対差を平均した値を色差とし、以下の式で得点を算出：

```
score = round(750 × Lerp(1.75, 0.1, difference))
```

### 判定ランク

| ランク | 色差範囲 | 説明 |
|---|---|---|
| Perfect | < 0.05 | 完全一致に近い |
| Excellent | < 0.15 | 高い精度 |
| Great | < 0.30 | 良好な精度 |
| Good | < 0.50 | 一定の精度 |
| Bad | ≥ 0.50 | 低精度 |

### スコアランク

5ラウンドの合計スコアの正規化値に基づいて以下のランクを付与：

| ランク | 条件 |
|---|---|
| S | 95%以上 |
| A | 90%以上 |
| B | 70%以上 |
| C | 80%以上 |
| D | 80%未満 |

## ホーム画面

色チャンネルデータ管理、RGB事前調整、スコア履歴表示、オプション（音量調整）を提供。初期データの選択後、ゲーム開始。
